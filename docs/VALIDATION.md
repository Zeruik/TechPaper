## preview.17 · 润色中的阈值保护

四对合成反例保留原数字和引文，仅改变边界含义：严格小于改为小于等于、等于改为不等于、至少改为至多，以及英文 at most 改为 at least。对同一批输入，preview.16 对应源码拦截 0/4，修订后拦截 4/4。另有两条等价符号改写通过（≥ 与 >=、!= 与 ≠）。源码通过 `build.ps1 -AppOnly -Test -DesktopTest`。在 preview.17 实际安装目录内加载主程序复验，同样拦截 4/4，允许 2/2。仅测试了列出的边界变化。

## 学术写作与翻译误报

Microsoft Translator Human Parity Data v1.0 提供同一批中文新闻的从零人工英译 HT、人工译后编辑 PE 及机器英译 Combo-4。按文件行测试全部 2,001 个对应位置。另取 WMT17 zh-en test 前 100 个中文输入作对应检查。新闻句段的语域与论文不同，资料没有提供每位译者的母语，不能据此估计非母语作者群体误报率。

| 真实来源或受控操作 | 条数 | AI | MIX | HUMAN | 弃答 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 人工英译 HT | 2,001 | 0 | 0 | 0 | 2,001 |
| 人工译后编辑 PE | 2,001 | 0 | 0 | 0 | 2,001 |
| 机器英译 Combo-4 | 2,001 | 0 | 0 | 0 | 2,001 |
| WMT 中文输入 | 100 | 0 | 0 | 0 | 100 |
| 公版中文及原生英文对照 | 2 | 0 | 0 | 0 | 2 |
| 合成 AI 对照 | 3 | 1 | 0 | 1 | 1 |
| 公版原文加模型续写 | 1 | 0 | 0 | 0 | 1 |

人工英译误报 0，明确漏判为 HUMAN 的机器英译 0，机器英译未检出 2,001（均弃答）。合成 AI 有 1 条错误指向 HUMAN，1 条弃答。翻译三组的判定覆盖率都是 0%。本次结果不支持用这套规则判定论文作者。

在合成中文实验说明中删掉冗余开场后，基线结果由 AI 变为弃答；这仅验证该条规则对措辞敏感。合成英文中故意引入单复数错误，结果仍为 HUMAN；短句、四个平行短句、长短句拼接均弃答。错误注入只用于合成测试。测试脚本为 tests/translation_regression.py。

数据只在本机作研究评测。来源为 Hany Hassan 等，*Achieving Human Parity on Automatic Chinese to English News Translation*，2018。[论文](https://arxiv.org/abs/1803.05567) · [Microsoft 数据与研究许可](https://www.microsoft.com/en-us/download/details.aspx?id=56724) · [WMT17](https://huggingface.co/datasets/wmt/wmt17)

## 工程验收

- DOCX 样件覆盖多文本运行、引用上标 [7]、普通上下标、编号列表、标题、1.5 倍行距、段后距、分节、表格、图片、批注、修订及参考文献。检查必要 XML 结构及未修改部件，测试逐段选择、换行、正负数/常用单位校验、同名保护、导出重开及原稿哈希。
- 本机私有样本只公开结构指标。174 个非空主文档段落未命中规则改写。原稿和清理副本均含 8 个表格、2 个分节、15 个内嵌图。测试工作目录与发行文件隔离。
- 离线 OCR 用清晰的中英双行测试图验证 PNG 与 JPEG、PPTX 原始文字与嵌图、三页 PDF 的文字页、纯扫描页及空白页。识别出中英文与数字，报告标记页/幻灯片/像素框。未知样本识别正确率尚无统计。
- 长文测试包含 12,000 个相同段落，逐句高亮 ID 唯一，末段存在，本地语料命中有源位置，HTML 特殊字符正确转义。测试中文空格路径、DOCX 拖放事件到实际导入、损坏 DOCX/PPTX/PDF/PNG、不支持扩展、同名报告及运行中取消清理。GUI 集成测试使用 tests/DesktopChecks.cs。
- 离线报告进程禁用 Python 的连接/解析网络请求与 ONNX Runtime 遥测。已装权重直接从磁盘加载。桌面默认不调用 GPTZero 或 Ollama。没有针对全部原生 DLL 做持续抓包或在所有 Windows 版本运行。
- 小模型评估采用来自 Qwen 官方的 Apache-2.0 Qwen2.5-0.5B-Instruct Q4_K_M，通过本机 Ollama 运行。一次合成输入触发数字/结构保护，另一例正常返回原句。这个模型的样本表现不足以推荐它自动修改整篇论文。未开展盲评或语义保真率统计。
- SVG 来自本项目提供的稿纸与检查标记候选。实际渲染检查 Windows ICO 的 16/32 像素、浅深背景和双主题工作台，核对可操作按钮的键盘焦点。应用声明系统 DPI 感知；尚无多台异构 DPI 显示器迁移测试。

私有原稿和导出副本均已用本机 WPS 排版引擎重开，重新渲染为 25 页。逐页以 96 dpi 比较，25/25 页像素完全一致。该样本没有正文措辞修改；未使用独立安装的 Microsoft Word 重跑。

### 独立离线候选对照

使用 2018 年《机械工程与技术》四篇互无重叠署名的现代论文，每篇使用同文中英文摘要，并各配一段本轮按主题生成的中英文合成稿（同一生成者）。期刊原文标 CC BY 4.0。英文摘要为发表的英文版本，翻译过程及译者未知。研究者的中文母语背景和摘要翻译方式均未推断。原稿、英文版本与合成稿按论文分组，生成者未独立切分，未进行跨模型验证。

| 分组 | 论文与署名 | 用途 |
|---|---|---|
| 开发 | [黄海斌等，焊接应力](https://doi.org/10.12677/met.2018.73022) | 各语言各取一对参照文本 |
| 验证 | [王胜春等，塔机结构](https://doi.org/10.12677/met.2018.71002) | 独立查看固定阈值 |
| 测试 | [刘洋志等，陶瓷基板](https://doi.org/10.12677/met.2018.71008)、[刘红宇，轴承](https://doi.org/10.12677/met.2018.73026) | 同论文两语与合成稿共同留出 |

A 使用发布版句级规则，文档出现 AI/MIX 即提示生成，否则有 HUMAN 则提示人工，其他均弃答。B 按语言将文本小写、空白合一，统计相邻三个字符的频数，以和生成、发表两参照向量的余弦相似度之差作为方向分。固定阈值 +0.04、−0.04，中间弃答。阈值在运行验证与测试前固定。B 仅用于实验。

| 留出组 8 段（每种语言两段发表、两段生成） | A | B |
|---|---:|---:|
| 有判断 / 全部 | 0/8 | 3/8 |
| 发表文本误标生成 / 发表文本 | 0/4 | 0/4 |
| 生成文本漏检（含弃答） | 4/4 | 4/4 |
| 生成召回（含弃答） | 0/4 | 0/4 |
| 中文 / 英文弃答 | 4/4、4/4 | 4/4、1/4 |

B 将两段发表英文摘要判为人工，也把一段生成英文误判为人工。现代中文改稿前后 B 分别为 +0.0123 与 +0.0198，均在弃答区。该方向分不表示概率。数据规模小，且生成对照共享生成者；本实验不支持提供生产级“AI率”，也不能估计某个群体的误报率。

### 混合页面

合成的双栏 PNG 展板含跨栏标题和两栏各四行。混合 PDF 在同一页同时放入可选文字和展板图。源码版离线 OCR 在 PNG 恢复 9 行，混合 PDF 恢复同样 9 行及独立文字层 1 行，两者均按标题、左栏、右栏输出。坐标对齐到页面渲染后的整页像素。仅验证这种明确中央栏沟的布局，原生 Canva 工程和任意复杂图形排布未测。

### 同架构的翻译对照补测

在上述四组已发表中文摘要上额外生成英文译稿，标记为“已发表中文原作，经模型翻译”。开发、验证、测试沿用同一论文分组，同时保留期刊英文版。两个三字符候选都使用同一开发集和同一生成参照；增强候选计算发表英文与新增的模型译稿两个人工原作参照中的最大相似度。阈值在验证组按“发表与翻译均零次判 AI，且阈值至少 0.04”锁定，两者均得 0.04。阈值两侧对称。此为追加的探索性实验，沿用上轮留出稿件，未获得全新盲测集。

相同的两个留出组上，两候选的结果相同。发表英文 2/2 判 HUMAN，模型翻译 1/2 判 HUMAN、1/2 弃答，独立生成 1/2 误判 HUMAN、1/2 弃答。三组 AI/MIX 均为零。覆盖 4/6，翻译原作误标代写 0/2，含弃答的生成召回 0/2。未达到识别生成稿的要求，未将候选加入默认软件。

补充空间定位检查：PNG 与混合 PDF 中九行的 36 个角点相对预设平移量均在 2 像素内。另以有框线的两列三行 PDF 表格和内嵌双栏海报（含两条 14 px 小字）测试。表格三行文字顺序正确，海报 11 行均有输出，右栏小字“Tolerance 0.25 C”的两个空格被 OCR 合并，数值保留。PDF 以文字行展示表格，列和单元格结构未重建。

### 开发版 · 跨 Word 文字片段的编辑保护

Word 可把一个短语拆成多个文字片段，例如把 at 和 least 5 mL 分在两段不同格式的文字中。原有逐片段检查会接受把 least 改成 most，因为在被改片段内看不到完整限定词。修订后，本机模型返回的多片段结果和手动编辑都在应用前检查整段拼接结果。合成模型响应中的反转已拦截，手动反转被拦截且先前预览不变；保留阈值的措辞修改仍可采用。

另用含斜体片段的合成 DOCX 检验规则润色。把“我们认为值得注意的是，样本量有限。”拆在“认为”之后，旧规则会误删后半片段的开头。现对分片与连续正文的规则结果做核对，有分歧时保留整段。另一段正常将 in order to 精简为 to，另存后重开核对主文档 XML，仅预期文字发生改变。源码及桌面回归通过；这些修复尚未进入 preview.17 安装包。此项测试没有验证 Word 实际分页。

## preview.18 · DOCX 图文顺序

## 开发版 · 清理预览中的 Word 身份信息域

清除核心属性后，页眉、页脚或正文中的 Word 域仍可能显示已缓存的作者、文件路径或属性值。开发版在导出前按 DOCX 内部部件列出 AUTHOR、LASTSAVEDBY、USERNAME、USERINITIALS、USERADDRESS、FILENAME 和 DOCPROPERTY 域的数量。预览只报位置和数量，不复制缓存值。用户可回原稿核查显示文字；默认清理和额外批注清理均保留这些域结构。

合成页眉包含简单文件名域、跨文字片段的最后编辑者域及页码域，页脚包含嵌套作者域。两种模式均正确列出页眉 2 处、页脚 1 处，页码未计入；导出的页眉、页脚与原部件逐字节一致。另用开发构建的实际隐私对话框切换两种清理模式，均显示文件名域位置且未显示合成缓存值。该项检查覆盖所列 Word 域，正文直接署名、嵌入对象、图像元数据及外部链接等仍须另外核查。preview.18 安装包尚未包含此预览。
