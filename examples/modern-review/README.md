离线覆盖率前后均为零。GPTZero 基础扫描均显示 4.1m，AI 分类增加 51 个百分点。修订稿网页计数 472，TXT 按含换行口径计 475。网页标记文本已更新，两稿均有少于 100 词的准确性提示。GPTZero 的分类置信度不可解释成 AI 撰写的字数比例。

修订把“对三个序列的峰值进行了比较”改为“比较了三个序列的峰值”。可在两份 TXT 中核对采样间隔和各峰值，在两份 DOCX 中查看页眉、带编号的标题和引用上标。主文档改了四个文字节点；擦除文字后，两份主文档规范化 XML 相同。本例启用隐私清理，缩略图被移除，属性部件与根关系也有变化。文字长度改变可以引起自然换行。
